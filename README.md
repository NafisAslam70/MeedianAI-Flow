# MeedianAI Flow (v2)

A later iteration of the MeedianAI Flow school and community operations platform. The application includes a Next.js dashboard and API routes, with database, authentication, storage, communication, and translation integrations.

## Tech
Next.js 15, React 19, PostgreSQL, Drizzle ORM, Prisma, Redis, Tailwind CSS, and integrations including Cloudinary, Twilio, and translation/AI providers.

## Run locally
```bash
npm install
npm run dev
```

Configure the database and any required service credentials in environment variables. See `TECH_STACK.txt` for a fuller inventory of dependencies.
