# MeedianAI Flow

A role-based school and community operations workspace built with Next.js. This repository is the base/earlier version in the MeedianAI Flow series.

## Verified areas
- Shared dashboard for task and routine tracking
- Admin, team-manager, and member dashboards
- Daily routines, day opening/closing, and user profiles
- Announcements, task assignment, and approvals

## Tech
Next.js 15, React 19, NextAuth, PostgreSQL (Neon), Drizzle ORM, and Tailwind CSS.

## Run locally
```bash
npm install
npm run dev
```

A PostgreSQL database and authentication environment variables are required for data-backed features. Check the app configuration before deployment.

See [MeedianAI-Flow-v1](https://github.com/NafisAslam70/MeedianAI-Flow-v1) and [MeedianAI-Flow-v2](https://github.com/NafisAslam70/MeedianAI-Flow-v2) for later iterations.
